Repos

Everything here runs in simulation. Each README says how to run it and where it fails.

RepoWhat it isStackCI
ur5e-teaching-controllers ros2_control effort controllers for a simulated UR5e: joint-space tracking (PID, PID with RNEA feedforward, computed torque) on Pinocchio or KDL dynamics, gravity-compensated hand guiding with a runtime payload model, and damped-least-squares TCP jogging. C++ for the control loop (controllers, dynamics backends); Python for orchestration and plots. ROS 2 Lyrical, ros2_control, Gazebo Jetty, Pinocchio, KDL.
pointcloud-constrained-planning Keep-the-cup-upright constrained planning for a simulated UR5e through a shelf that MoveIt 2 only knows from an octomap built live from a simulated RGB-D camera, benchmarked against a pipeline written directly on OMPL, Pinocchio and coal. C++ for the planning path (benchmark nodes, constraint builder, the direct pipeline); Python for launch, aggregation and plots. ROS 2 Lyrical, MoveIt 2 (MoveItCpp), OMPL, Pinocchio, coal, Gazebo Jetty.
humanoid-upper-body-retargeting Webcam to Unitree G1 upper-body retargeting in MuJoCo: MediaPipe Pose, a One-Euro filter and analytic plus damped-least-squares IK on both arms, recordable as LeRobot datasets. The animation and current results come from a synthetic fixture until the webcam recording replaces them. Python for orchestration, recording and benchmarks; C++ for the per-frame filter and IK core through pybind11. MuJoCo, MediaPipe, LeRobot; CPU only.
sim-demo-to-policy A MuJoCo pick-and-place task on a Franka Panda: scripted demonstrations recorded as LeRobot datasets, ACT and a small from-scratch spatial-softmax BC policy trained on a laptop CPU, and an evaluation harness with held-out seeds, a failure taxonomy and confidence intervals. Python only: the imitation-learning stack is Python. MuJoCo, LeRobot, PyTorch; CPU only.
